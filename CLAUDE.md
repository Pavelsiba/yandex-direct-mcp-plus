# CLAUDE.md

Указания для Claude Code при работе в этом репозитории.

## Что это

MCP-сервер (stdio) поверх API Яндекс.Директа v5: 60 инструментов — кампании, группы,
объявления, ключевые фразы, ставки, минус-фразы, временной таргетинг, статистика,
словари. Первая версия собрана на коде `theYahia/yandex-direct-mcp` (MIT), дальше
развивается самостоятельно; благодарность — в README.

Лицензия — AGPL-3.0-only (до 1.7.0 — MIT). Платный хостинг живёт в отдельном закрытом
репозитории и подключает этот пакет зависимостью, поэтому чужой код сюда попадает только
с CLA — включая скопированные фрагменты под несовместимыми лицензиями.

- Архитектура, инварианты и обоснования оснастки — `docs/architecture.md`. Читать до
  того, как решать, куда класть новый код.
- Планы и решения — **issues репозитория**, по одному на задачу.
- `docs/roadmap.md` — замороженный архив до 13.09.2026: читать для контекста, не править.

## Команды

```bash
npm run build          # clean + tsc -p tsconfig.build.json → dist/
npm test               # vitest run --project unit (без сети)
npm run test:watch
npm run test:int       # сетевые тесты по боевому API — только осознанно
npm run dev            # tsx src/app/index.ts, без сборки
npm run dev:http       # удалённый сервер по HTTP из исходников (нужен YD_MCP_SECRET)
npm run probe          # разовый скрипт с окружением: npm run probe -- <файл>.ts
npm run lint           # biome check (формат + линт)
npm run lint:fix       # biome check --write
npm run typecheck      # tsc --noEmit: src, тесты и конфиги
npm run lint:dead      # knip
npm run lint:workflows # actionlint + zizmor по .github
npm run lint:secrets   # gitleaks по всей истории, с --redact
npm run api:snapshot   # WSDL → docs/api-v5.md (сеть, токен не нужен)
npm run api:fields     # снимок → src/shared/config/api-fields.ts (офлайн)
npm run docs:tools     # реестр → таблицы инструментов в README (офлайн)
```

После правок исходников — `npm run build`: MCP-клиенты запускают `dist/app/index.js`.
Линтеры и сканеры запускать через `npm run`, а не `npx`: без локального пакета `npx`
скачает из npm одноимённый посторонний.

## Архитектура — коротко

```text
src/
  app/            композиция: сервер, реестр инструментов, точка входа
  tools/<домен>/  schema.ts (контракт) · handler.ts (сценарий) · tool.ts (дескриптор)
  shared/api/     клиент v5 / v4 / отчёты, retry, разбор ошибок, проверка формы ответа
  shared/lib/     money, id, pagination, format, date, report, tool (defineTool)
  shared/config/  эндпоинты, окружение, лимиты, перечисления
  testing/        подмена транспорта для тестов, в сборку не попадает
```

Зависимости идут `app → tools → shared`: инструмент не импортирует инструмент, `shared`
не знает про `tools` и `app` (сторожит `noRestrictedImports` в `biome.json`). Между
слоями — подпути `#shared/*`, `#tools/*`, `#app/*`, `#testing/*`; внутри домена —
относительные импорты. `npm run dev` обязан идти с `--conditions=development`, иначе
`tsx` исполняет прошлую сборку из `dist/`.

Новый инструмент = каталог в `tools/<домен>/`, дескриптор через `defineTool`, явный
импорт в `app/registry.ts`, тест рядом с кодом (процедура — скилл `new-tool`).
Аннотация (`READ` / `WRITE` / `IDEMPOTENT` / `DESTRUCTIVE`) — по реальной природе
операции: на неё полагаются клиенты.

## Обязательные соглашения

**Деньги.** API оперирует микроединицами (сумма × 1 000 000), наружу сервер отдаёт и
принимает рубли. Вход конвертирует схема, выход — `format`; хендлер на миллион не умножает.

**ID — строки, всегда.** 64-битные ID Директа (19 знаков) не помещаются в `Number`.
Наружу — десятичные строки через `idField`, внутрь — `BigInt`. `z.coerce` на ID-полях
запрещён: он принял бы уже округлённое число. JSON разбирается и сериализуется только
через `parseJson`/`stringifyJson` в `shared/api` (держит GritQL-плагин Biome).

**Перечисления — `z.literal([...])` со значениями из WSDL** (`docs/api-v5.md`, руками не
править), а не со страниц справочника — те отдают неполные списки. Неподтверждённый
список остаётся `z.string()` с перечислением в описании. Описание поля —
`.meta({ description })`, текст ошибки — `{ error: "..." }`.

**`FieldNames` — из `API_FIELDS`** (`src/shared/config/api-fields.ts`, генерируется
`npm run api:fields`), не рукописным списком.

**Ошибки** — разбирает `shared`: ошибка запроса v5 приходит телом с HTTP 200, per-item —
в `*Results`, обрезанная выборка — в `LimitedBy`. В хендлерах ошибки не обрабатываются.

**Update = полная замена.** `NegativeKeywords.Items`, сайтлинки, привязки наборов
перезаписываются целиком: прочитать текущее значение и отправить объединённое.

**Детерминизм.** `Date.now()` и подобное приходят в хендлер параметром или из
подменяемого хелпера.

**Язык.** Описания инструментов, сообщения об ошибках, комментарии и коммиты — на русском.

**Секреты — не читать, не печатать, не обходить запреты.** Значение OAuth-токена и любого
другого секрета не выводится никуда: ни целиком, ни фрагментом, ни длиной, ни «чтобы
убедиться, что задан». Нужен факт о секрете — спросить пользователя. В шелл секрет
попадает только подстановкой (`"Bearer $TOKEN"`), никогда — текстом.

Запреты в `.claude/settings.json` (`deny` на Read/Write и хук `deny-secrets.mjs`) не
обходятся **ни в какой форме**: ни другой записью (`process["env"]`), ни другой утилитой,
ни флагом, ни переносом строки в файл. Сработавший запрет — сигнал остановиться и сказать
пользователю, чего не хватает. Хук проверяет текст команды, а не действие, поэтому
настоящее правило — здесь (05.09.2026 прежний хук обошли дважды).

## Окружение

- `YANDEX_DIRECT_TOKEN` — обязателен; `YANDEX_DIRECT_LOGIN` — Client-Login для агентских
  токенов.
- Локально значения живут в `.env` (в `.gitignore`), его читают `npm run dev`,
  `npm start` и `.mcp.json` через `--env-file-if-exists=.env`. Код `.env` не знает:
  `shared/config/env.ts` берёт только `process.env`.
- Секрет в отслеживаемый файл не кладётся ни при каких условиях: 03.09.2026 токен уехал
  в `.mcp.json` и двое суток пролежал в публичном репозитории.

**Тестовой среды нет.** Песочница Директа отключена с июля 2026, любой вызов идёт по
боевому аккаунту. Пишущие инструменты проверяются только на кампании-полигоне в черновике
(`Status: DRAFT`, `State: OFF`) и только по явной просьбе; `moderate_ads` на полигон не
звать. Процедура — скилл `direct-probe`, ID полигона — в `CLAUDE.local.md`.

## Git

- Под каждую задачу — своя ветка от `dev` по типу коммита (`feat/…`, `fix/…`, `chore/…`,
  `ci/…`, `docs/…`, `refactor/…`), назад — pull request'ом в `dev`.
- Пушим только в `dev` и ветки задач. `main` наполняется исключительно мерджем PR из
  `dev` на GitHub, там же отрабатывает semantic-release.
- **Коммитить и пушить — только по явной просьбе.** «Сделай X» — не разрешение на коммит;
  разрешение на один шаг не распространяется на следующие.
- Conventional commits на русском. Подробности и хуки — скилл `git-commit`.

## Подводные камни

- Тесты не ходят в сеть: `installFetchMock()` подменяет транспорт через `setTransport`
  (`shared/api/fetch.ts`). Отсюда запрет на `vi.resetModules()` — свежая копия модуля
  получает боевой транспорт; кэш сбрасывается своим экспортом (`clearDictionaryCache`).
- Файлы правятся инструментами `Edit`/`Write`, шелл получает команды, а не содержимое
  исходников: иначе запрет на `.env` срабатывает на `process.env` внутри текста модуля.
  Сужать запрет ради этого нельзя — чинится приёмом, а не шаблоном.
- gitleaks, actionlint, zizmor и shellcheck — не npm-пакеты; без них хуки `secrets` и
  `workflows` валят коммит. Установка — README, раздел «Разработка».
- SDK — v2 (`@modelcontextprotocol/server`), не `@modelcontextprotocol/sdk` 1.x: тот
  отдаёт схемы в `draft-07`, и строгие клиенты их отклоняют.
