# Changelog

добавляет semantic-release по conventional commits; версионирование —
[SemVer](https://semver.org/lang/ru/). Коммиты типов `chore`, `ci`, `build`,
`style` и `test` в файл не попадают — политика типов задана в `.releaserc.json`.
